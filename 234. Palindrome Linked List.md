# Palindrome Linked List (LeetCode 234)

## 1. Intuition

A Palindrome is a sequence that reads the same from left to right and right to left.

For example:

1 → 2 → 2 → 1

This is a palindrome because it is the same in both directions.

In this approach, we create a **reversed copy** of the original linked list and then compare both lists node by node.

If all corresponding node values are equal, the linked list is a palindrome. If any value is different, it is not a palindrome.

### Why did I choose this approach?

* It is simple and easy to understand.
* We create a reversed copy of the original linked list.
* Then we compare the original list with the reversed list.
* If both lists are exactly the same, the original linked list is a palindrome.

---

## 2. Approach

### Algorithm

1. If the linked list is empty or contains only one node, return `true`.
2. Create a pointer `r_head` and initialize it to `NULL`.
3. Traverse the original linked list using `ptr`.
4. For every node:

   * Create a new node containing the same value.
   * Insert this new node at the beginning of `r_head`.
   * This creates a reversed copy of the original list.
5. After creating the reversed list, use two pointers:

   * `head` for the original list.
   * `r_head` for the reversed list.
6. Compare their values one by one.
7. If any two values are different, return `false`.
8. If all values are equal, return `true`.

### Time Complexity

* `O(n)`

We traverse the linked list twice:

* Once to create the reversed copy.
* Once to compare both lists.

Therefore, overall complexity is `O(n)`.

### Space Complexity

* `O(n)`

We create a new reversed linked list containing `n` nodes.

## 3. Code

```cpp
class Solution {

public:

    bool isPalindrome(ListNode* head) {

        // Some Brute Force Steps to follow

        // 1) Reverse the list and store it in r_head;
        // and then compare head->val and r_head->val
        // if equal move both the pointers otherwise
        // if not equal return false.

        // When the loop will be executed fully return true

        if(head == NULL || head->next == NULL){

            return (head);
        }

        ListNode *r_head = NULL;

        ListNode *ptr = head;

        while(ptr != NULL){

            ListNode *temp = new ListNode(ptr->val);

            temp->next = r_head;

            r_head = temp;

            ptr = ptr->next;
        }

        while(head && r_head){

            if(head->val != r_head->val){

                return false;
            }

            head = head->next;

            r_head = r_head->next;
        }

        return true;
    }
};
```

---

## 4. Example

### Input

`head = [1,2,2,1]`

Original Linked List:

1 → 2 → 2 → 1

### Operations

First, we create a reversed copy of the linked list:

1 → 2 → 2 → 1

After reversing:

1 → 2 → 2 → 1

Now we compare both lists:

Original:
1 → 2 → 2 → 1

Reversed:
1 → 2 → 2 → 1

All values are equal.

---

## 5. Output

`true`

---

## 6. Explanation

Initially, the linked list is:

1 → 2 → 2 → 1

We create an empty reversed list:

`r_head = NULL`

We traverse the original list and insert every value at the beginning of `r_head`.

After processing all nodes, the reversed list becomes:

1 → 2 → 2 → 1

Now we compare the original list and reversed list node by node.

First comparison:

1 == 1 → Equal

Second comparison:

2 == 2 → Equal

Third comparison:

2 == 2 → Equal

Fourth comparison:

1 == 1 → Equal

Since all values are equal, the linked list is a palindrome.

Therefore, we return:

`true`

### Important Point

If at any point:

`head->val != r_head->val`

then the linked list is not a palindrome, so we immediately return:

`false`
