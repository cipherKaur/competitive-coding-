# Implement Odd-Even Linked List (LeetCode 328)

## 1. Intuition

A Linked List contains nodes connected using pointers. In this problem, we need to rearrange the linked list so that all nodes at odd positions come first, followed by all nodes at even positions.

For example:

1 → 2 → 3 → 4 → 5

Odd position nodes:
1 → 3 → 5

Even position nodes:
2 → 4

Final Linked List:
1 → 3 → 5 → 2 → 4

To solve this, we use three pointers:

* `odd` – points to the current odd-position node.
* `even` – points to the current even-position node.
* `temp` – stores the first even node so that we can attach the even list after the odd list.

### Why did I choose this approach?

* It rearranges the existing linked list without creating new nodes.
* It uses pointers to separate odd and even positioned nodes.
* It requires only constant extra space.
* It is efficient and easy to implement.

---

## 2. Approach

### Algorithm

1. If the linked list is empty or contains only one node, return `head`.
2. Initialize `odd` with the first node:
   `odd = head`
3. Initialize `even` with the second node:
   `even = head->next`
4. Store the first even node in `temp`:
   `temp = head->next`
5. Traverse the list using a loop.
6. Connect the current odd node to the next odd-position node:
   `odd->next = odd->next->next`
7. Connect the current even node to the next even-position node:
   `even->next = even->next->next`
8. Move both pointers forward:
   `odd = odd->next`
   `even = even->next`
9. After the loop, attach the even list after the odd list:
   `odd->next = temp`
10. Return `head`.

### Time Complexity

* `O(n)`

Each node is processed while traversing the linked list.

### Space Complexity

* `O(1)`

Only a few pointers are used, so no extra data structure is required.

---

## 3. Code

```cpp
class Solution {

public:

    ListNode* oddEvenList(ListNode* head) {

        if(head == NULL || head->next == NULL)
            return head;

        ListNode* odd = head;

        ListNode* even = head->next;

        ListNode* temp = head->next;

        while(odd && odd->next && even && even->next) {

            odd->next = odd->next->next;

            even->next = even->next->next;

            odd = odd->next;

            even = even->next;
        }

        odd->next = temp;

        return head;
    }
};
```

---

## 4. Example

### Input

`head = [1,2,3,4,5]`

The original linked list is:

1 → 2 → 3 → 4 → 5

### Operations

Odd-position nodes:

1 → 3 → 5

Even-position nodes:

2 → 4

After connecting the odd list with the even list:

1 → 3 → 5 → 2 → 4

---

## 5. Output

`[1,3,5,2,4]`

---

## 6. Explanation

Initially, the linked list is:

1 → 2 → 3 → 4 → 5

`odd` points to `1` and `even` points to `2`.

We also store `2` in `temp` because `2` is the first node of the even-position list.

After changing the pointers:

Odd list:

1 → 3 → 5

Even list:

2 → 4

Now `odd` is pointing to the last odd-position node `5`.

We use:

`odd->next = temp`

This connects the last odd node to the first even node:

1 → 3 → 5 → 2 → 4

Therefore, the final output is:

`[1,3,5,2,4]`
